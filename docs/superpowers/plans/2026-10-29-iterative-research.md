# 交互迭代研究实施记录

本计划执行用户在会话中确认的五批方案。目标、约束和模块边界见 [交互迭代研究框架](../specs/2026-10-28-interactive-research-framework-design.md)。实施与验收以代码和测试结果为准；未验证或受阻的来源继续列为未完成。

- [ ] 第一批：建立基线，统一资料版本格式，将已有多来源搜索和正文/讨论能力接入默认调查，改进中文查询。
- [ ] 第二批：持久化研究问题、未完成动作和分页位置，使追问实际改变采集，并保留中断后的资料。
- [ ] 第三批：逐项接入和验证十二个约定平台，包括按需复用授权会话和受阻状态。
- [ ] 第四批：版本化原文分段检索、跨调查复用、证据组织及网页/MCP 交互完善。
- [ ] 第五批：五类真实问题的三轮调查、内容级搜索产品对照与验收收口。

默认采集 120 秒；规划和采集共享截止时间，整理另限 60 秒。用户发起每轮；来源限制适用于采集与历史复用。每批包含适用的自动化测试、真实样本和未完成原因。

## 2026-10-29 实施进度

- 已将公开网页、可选搜索服务、多个公开社区和学术来源接入调查；小红书、抖音、快手复用无头浏览器入口，其中快手尚无讨论深采。网页与 MCP 共用服务，来源进度和资料覆盖随事件返回。
- 已保存搜索计划、平台资料版本及原生回复关系；追问可回查相关未读对象后继续新搜索，旧线索使用有上限的重叠扫描。回答按词面相关度选取长文片段并尽量覆盖不同网站。
- 已用隔离匿名样本取得 CSDN、B站正文或简介和少量评论；知乎、微博、小红书、抖音、快手的匿名探测分别遇到失败、超时或验证，不能据此声称平台深采已验收。详见 [自主爬取与检索](../../native-crawler.md)。
- 五批尚未完成：子问题与信息缺口状态、可恢复分页游标、真正按结果自适应的调度、版本绑定的分段索引、全部平台真实验收与竞品对照仍待实现。现有并发限制是来源任务及单后端浏览器位置，并非全局 HTTP 限流。
