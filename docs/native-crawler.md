# 自主爬取与检索

Periscope 可以在已有搜索、平台和订阅源之外，沿站点结构主动发现资料。爬虫得到的网页正文、PDF 文本和 Excel 单元格进入同一个话题结果、运行记录和语料库，关闭 DeepSeek API 后也能独立工作。

## 两种入口

自动跟进本轮资料：

```text
periscope-topic --topic "人形机器人" --crawl --no-api
```

爬虫优先选择本轮原生直采结果，再使用可用的 API 结果；最多从六个入口开始，优先分散到不同站点。API 关闭时仍使用直采链接。普通查询保持原有耗时范围，只有指定 `--crawl` 或 `--crawl-seeds` 才启用额外爬取。

直接从指定站点开始：

```text
periscope-topic --topic "attention" --crawl-seeds https://arxiv.org/abs/1706.03762 --crawl-pages 6 --crawl-depth 1 --crawl-budget 45 --no-api --speed off --save
```

`--speed off` 关闭原有平台采集；指定的爬虫仍执行。可以把种子替换成院校公告列表、研究机构页面、政府目录或站点地图地址。爬虫从入口发现同一组种子域名内的列表链接、详情链接和 PDF，优先处理话题相关链接与 PDF，也读取 robots 声明的站点地图。站点地图提供 URL 发现，不能保证覆盖该站所有内容。

## 当前提取能力

- HTML：提取正文、表格的可读文本，发现详情、分页和附件链接；正文最多 60,000 字符。
- PDF：提取文本层，每份最多读取 40 页，保存页码、文本范围及 `#page=N` 链接；扫描页标记为需要 OCR，不生成不存在的正文。
- Excel `.xlsx`：按工作表和原行号提取非空单元格，保留例如 `B2=365` 的坐标和值；每行在文档元数据中保存工作表名、行号及文本范围。最多读取 20 个工作表、5,000 行、128 列和 60,000 字符，超限标记 partial。压缩包展开后超过 40 MiB 或包含超过 4,096 项时拒绝解析。公式保留表达式，不执行计算。
- 站点地图：支持 `urlset` 和 `sitemapindex`，在深度、页数和队列上限内继续发现页面。
- 普通文本：读取文本内容；不执行网页脚本。

大型站点的“入口 → robots 声明地图索引 → 子地图 → 文章”需要 `--crawl-depth 3`；也可以直接把子地图作为入口。默认两层可能只完成地图发现。

每条资料保留入口、父页面、发现深度、观察时间、正文所属 URL、文档类型及原始内容 SHA256。相同 URL 的内容字节发生变化时，显式入库会保留不同版本。当前保存的是提取文本与内容指纹，不是原始网页或 PDF 的完整归档；字节变化也可能来自页面模板，尚未自动判断是否为实质改动。

PDF 页码和 Excel 工作表、行号等文档信息贯穿 JSON、运行分片、入库和历史检索。HTML/PDF/Excel 解析在可终止的子进程中执行，网络预算结束时不会等待仍在解析的文档。已有成功资料在内部预算超时或某页失败时保留，使用者中断进程前未完成的运行不保证已经落盘。

## 范围与结果

默认最多尝试 12 个页面、跟进两层，独立时间预算 30 秒，每份响应最多 5 MiB。页数上限包含失败和未匹配页面；robots 请求与跳转另计入请求数。网络逐主机限速，并遵守 robots 和其 crawl-delay；重定向同样检查域名、公开网络地址和目标路径的 robots。

爬虫不把列表里出现一个关键词就当作已取得全部资料。只有提取的标题或正文匹配话题时才形成检索记录。链接发现、正文为空、需要 OCR、格式不支持、失败、限制阻止、超过大小或预算，均在 `crawl_reports` 中单独记录。汇总状态区分空结果、失败和部分成功。

`--crawl-budget` 与原有 `--budget` 分别限制爬虫和原生平台采集，均不包含 API、本地检索与可选视频富化。正文提取不等于事实核验；发现路径和相同 URL 的多个版本不构成独立信源。

## 验证

2026-10-19，在不调用搜索 API 的情况下，从公开的 `https://arxiv.org/pdf/1706.03762` 提取到 39,613 字符论文文本，并保存逐页位置。结果位于 `.periscope-scratch/crawler-pdf-live-20261019.json`。另一次 20 秒预算的双入口查询保留了已完成的摘要页，把未完成 PDF 记录为超时。

测试覆盖列表到详情/PDF、robots 声明地图中的未直接链接页面、逐页定位、解析子进程取消、边界限制、不同版本保存及再次检索。它们证明自主采集链路可用；未据此宣称上述公开论文是某个搜索 API 无法检索的独家资料。

最终全项目测试 1,341 项通过，其中本轮新增爬虫测试 22 项。安装包在源码目录之外通过真实本地 HTTP 页面、PDF 子进程、显式保存、出处检索和不同版本保存的完整验证。

当前尚未实现扫描件 OCR、旧版 `.xls`、Word 解析、合并单元格和跨行表头的语义恢复、跨站无限递归、通用浏览器渲染或登录会话接管。Excel 输出保留原始单元格位置，不自动推断跨行表头或将录取数值解释为结构化结论。已有小红书、抖音等平台适配继续走独立模块。后续平台扩展应以真实漏检样本和新增有效证据衡量。
