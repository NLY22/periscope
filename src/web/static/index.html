使用指南

从一个问题开始

在深度调查中输入问题，或指定公开网址。采集会在后台进行，你可以查看资料并继续追问。

把发现与出处放在一起

展开资料查看原文；点击回答中的编号可定位对应出处。调查记录可以在工作区重新打开。

资料与模型各有状态

连接模型后可获得简答；模型不可用时，仍可查看已经采集的资料。

一些顺手的小操作

Enter 发送问题，Shift + Enter 换行。Ctrl / ⌘ + K 打开资料检索。新建调查会保留已有会话。
